# To-do (JavaScript 미션 1)
 
`index.html` 파일을 브라우저로 열면 바로 실행돼요.
링큐의 디자인시스템을 좀 참고했어용 호호.
 
## 기능
- 입력창에 할 일을 적고 **Enter**로 "해야 할 일"에 추가
- **고리 버튼(완료)** → 두 고리가 맞물리는 애니메이션 + 축하 효과 후 "해낸 일" 메모지로 이동
- 해낸 일은 손글씨 메모지에 물결 취소선이 그어지며 기록
- **삭제** 버튼 → 접히는 애니메이션과 함께 제거
- 빈 문자열 / 공백만 입력 방지, 앞뒤 공백 제거, 진행 중인 항목 중복 방지
- 한글 입력 중 Enter 중복 추가 방지, localStorage 저장으로 새로고침해도 목록 유지
- 시스템의 "동작 줄이기" 설정을 켜면 애니메이션 생략
 
## 파일 구성
| 파일 | 역할 |
| --- | --- |
| `index.html` | 마크업 (header, input, 해야 할 일 section, 해낸 일 section) |
| `styles.css` | 디자인 토큰, 카드 · 메모지 스타일, 애니메이션 |
| `app.js` | 로직 (`addTodo`, `completeTodo`, `deleteTodo`, 이벤트 위임, 축하 효과) |
